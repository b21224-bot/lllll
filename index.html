C*는 농도 범위의 중간값입니다. 표면의 모든 점은 시간 t와 농도 C의 한 조합을 나타냅니다.

사용한 다변수 함수

P(t,C) = K / [1 + A e−(r−βC)t]

A = (K − P₀) / P₀이며, t는 시간, C는 항생제 농도, P는 세균 개체수입니다.

∂P/∂C = −K A β t e−gt / (1 + A e−gt)²

∂P/∂C는 시간을 고정했을 때 항생제 농도 변화가 세균 수에 미치는 순간적인 영향을 나타냅니다.

3D 표면 읽는 방법

  • X축(t): 시간이 흐를수록 세균 수가 어떻게 변하는지 확인합니다.
  • Y축(C): 항생제 농도를 높였을 때 표면의 높이(Z)가 어떻게 달라지는지 봅니다.
  • Z축(P): 해당 시간과 농도에서 모델이 나타내는 세균 개체수입니다.
  • 슬라이더를 조절하면 함수 표면과 요약 값이 즉시 다시 계산됩니다.

모델의 가정과 한계

항생제 농도가 유효 증식률을 g = r − βC처럼 선형적으로 낮춘다고 가정한 교육용 단순화 모델입니다. 실제 억제환 크기나 임상적 항생제 효과를 직접 예측하는 검증된 식은 아닙니다. 실제 결과에는 약물 확산, 배지 조건, 균주, 노출 시간, 최소억제농도(MIC) 등도 영향을 줍니다.

g > 0이면 증식, g = 0이면 모델상 개체수 변화가 없고, g < 0이면 감소합니다. P₀는 t = 0에서의 초기값입니다.
